# Convert a plot unless it already is a chart

Convert a plot unless it already is a chart

## Usage

``` r
stem_chart_from(plot, chart_args = list())
```

## Arguments

- plot:

  A ggplot or an `ms_chart`.

- chart_args:

  Arguments passed to
  [`stem_as_mschart()`](https://stem-cz.github.io/stemtools/reference/stem_as_mschart.md).

## Value

An `ms_chart`.
